About us

A community built by and for civic technologists.

Welcome to StealThisCode.org. We are a community built by and for civic technologists who believe in the power of open source collaboration to drive positive change. Our platform is a kind, supportive space to find, share, and adapt code snippets specifically for civic good projects.

We call it "stealing," but we mean it in the best way possible: resourcefully borrowing and building upon shared knowledge within a collaborative environment. Join us in making civic innovation more accessible, more practical, and more impactful, together.

Launch plan

Made for GitHub Pages and ready for your domain.

This site is a static, build-free starter. Put it in a GitHub repository, enable Pages, and point `stealthiscode.org` at the published site. The `CNAME` file is already included.

  1. Create a GitHub repository for the site inside the `Steal-This-Code` organization.
  2. Publish the root of the `main` branch with GitHub Pages.
  3. Point your DNS records to GitHub Pages and turn on HTTPS once the certificate is ready.
