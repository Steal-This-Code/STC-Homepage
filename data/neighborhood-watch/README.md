# Neighborhood Watch data contract

This folder is intended to hold static artifacts generated by
`scripts/build_neighborhood_watch_data.R`.

Expected outputs:

- `metadata.json`
- `summary_by_area.json`
- `offense_mix.json`
- `time_patterns.json`
- `place_types.json`
- `actions_by_profile.json`
- `incidents_recent.parquet`
- `boundaries.geojson`

Place source boundary files in `data/boundaries/` before running the build:

- `data/boundaries/neighborhoods.geojson`
- `data/boundaries/zip_codes.geojson`
